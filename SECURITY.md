# Security policy

## Supported versions

This repository is a portfolio / demo project. Security fixes are applied on the default branch when reported.

| Version | Supported |
| --- | --- |
| `main` | Yes |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email the maintainer listed in the GitHub profile for this repository, or use GitHub's private vulnerability reporting if it is enabled on the repo.

Include:

- A short description of the issue
- Steps to reproduce
- Impact (what an attacker could do)
- Whether you already have a suggested fix

You should receive an acknowledgement within a few days. Please give reasonable time before any public disclosure.

## Non-security issues

Bugs, docs gaps and feature ideas belong in GitHub Issues (once the repository is published).

## Local demo credentials

Development Compose seeds demo accounts with well-known passwords so reviewers can sign in immediately. Those credentials are **not** for shared or production use. See [docs/security.md](docs/security.md).
